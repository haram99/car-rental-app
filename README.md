# نظام تأجير السيارات (Streamlit)

تشغيل محلي:

    pip install -r requirements.txt
    streamlit run app.py

النشر: ارفع المجلد إلى GitHub ثم أنشئ تطبيقًا في share.streamlit.io واختر `app.py`.
البيانات في `rental.db` (SQLite). على الاستضافة المجانية قد تُمسح عند إعادة التشغيل، فاستخدم صفحة «النسخ الاحتياطي».
